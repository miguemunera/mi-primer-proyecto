# Bonita — Belleza & Bienestar

Landing de prueba para un spa de belleza en Laureles, Medellín.

Recuperada desde el deployment de producción en Vercel (`bonita-landing.vercel.app`,
proyecto `bonita-landing` en el equipo MunerAI), ya que la carpeta local original
se había borrado sin haber sido commiteada a Git.

- `src/index.html`: landing completa (HTML + CSS + JS inline).
- `src/vercel.json`: configuración de despliegue (clean URLs, sin trailing slash).

Sigue desplegada y en vivo en https://bonita-landing.vercel.app.
